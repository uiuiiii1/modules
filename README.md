## Key 模块：高级按键

> **参考来源**：本模块参照**江科大自化协（江科大众志）**的 STM32 入门教程实现。教程里的按键驱动基于"短按/长按"两种事件，本模块在其基础上扩展为七种事件（增加按住、释放、双击、重复触发），方便更复杂的交互场景（如长按连发、双击确认）。

**功能**：基于 GPIO 输入 + 定时器中断扫描的按键事件处理，支持 7 种按键事件：

| 事件 | 标志位 | 触发条件 |
|---|---|---|
| 按住 | `KEY_HOLD` | 持续按下 |
| 按下 | `KEY_DOWN` | 按下瞬间（边沿） |
| 释放 | `KEY_UP` | 松开瞬间（边沿） |
| 单击 | `KEY_SINGLE` | 按下后 200ms 内松开 |
| 双击 | `KEY_DOUBLE` | 单击后 200ms 内再次按下 |
| 长按 | `KEY_LONG` | 持续按下超过 2000ms |
| 重复 | `KEY_REPEAT` | 长按后每 100ms 重复触发一次 |

**时间参数**（可在 `Key.c` 顶部调整）：

```c
#define KEY_TIME_DOUBLE  200      // 双击最大间隔时间（ms）
#define KEY_TIME_LONG    2000     // 长按最小时间（ms）
#define KEY_TIME_REPEAT  100      // 长按后重复触发间隔（ms）
```

**默认绑定**：`GPIOC_Pin15`（上拉输入模式）。要改引脚只需修改 `Key_Init()` 中的 `GPIO_Pin`。

### 使用示例

```c
int main()
{
    Key_Init();       // 初始化按键
    // 把 Key_Tick() 放到 10ms 定时器中断里调用

    while(1)
    {
        // 查询事件（返回 1 表示事件发生，并自动清除标志）
        if(Key_Check(KEY_SINGLE))  { /* 单击事件 */ }
        if(Key_Check(KEY_DOUBLE))  { /* 双击事件 */ }
        if(Key_Check(KEY_LONG))    { /* 长按事件 */ }
        if(Key_Check(KEY_REPEAT))  { /* 长按重复 */ }
        if(Key_Check(KEY_HOLD))    { /* 按住中 */ }
    }
}
```

### 10ms 定时器中断调用

```c
void TIMx_IRQHandler(void)
{
    // ... 你的定时器中断代码 ...
    Key_Tick();   // 每 10ms 扫描一次按键
}
```

### 实现原理

`Key_Tick()` 内部用状态机（`s` 变量）跟踪按键状态流转：

```
s=0 (空闲) --按下--> s=1 (计时中) --超时2000ms--> s=4 (长按重复中)
s=1 --松开--> s=2 (等待双击/单击) --200ms内再按下--> s=3 (双击已确认)
s=2 --超时200ms--> s=0 (确认单击)
```

每次状态变化时往 `Key_Flag` 对应位写事件标志，`Key_Check()` 查询并清除标志（`KEY_HOLD` 除外，因为它是持续状态）。
